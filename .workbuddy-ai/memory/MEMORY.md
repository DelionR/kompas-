# Проект: KOMPAS-3D MCP (мост к КОМПАС-3D + щитовой домен)

## Окружение dev-машины

**КОМПАС-3D не установлен, pywin32 нет.** Живую проверку через COM выполнить
нельзя — каждый слой делится на **чистые функции** (тестируемы, не импортируют
`win32com`) и тонкий слой исполнения (мок в `test_wave1/3/4/5`). Приёмка на
живом КОМПАСе — за Романом.

Детали волн — `docs/WAVE7…16_CHANGES.md`; конкуренты —
`mcp_servers_comparison.md`.

## Главная дисциплина: отказ вместо выдумывания

Нет данных → `refusals` / `not_checked` / `unverified`, **никогда** не
правдоподобная подмена. Нормы и каталоги приходят от caller или из
`data/normative` с `source`, который возвращается в `provenance`.

## Ключевые факты домена щита

- Единицы — мм; начало координат сверху слева, `+y` вниз; в CAD только через
  `cabinet_layout.to_cad()`. `rail_offset_mm` — от верхней кромки до оси рейки.
- **Модуль IEK 18 мм, не 17,5** (18/36/54/72). УЗО шире: 2P 42 мм, 4P 77 мм —
  шаг не кратен. На плите 600 мм влезает 26 автоматов 1P, не 27.

## Приём: добыча таблиц ГОСТ из открытых публикаций

**HTML-двойник PDF на files.stroyinf.ru парсится, сам PDF — нет**: тот же
номер с `.htm` даёт таблицы в `<table>`. Проверено на трёх ГОСТ. Буквы в ГОСТ Р
50345 набраны кириллицей и латиницей вперемешку. Пересборка: скрипты в
`tools/`.

## Нормативные таблицы (волна 13, `src/normative_tables.py`)

Восемь таблиц в `data/normative/*.json` с provenance; подключить можно своими
строками, ссылкой `normative:<имя>` или фильтром. **Отбор строк
`table_filters` обязателен**: все строки ampacity сразу дали бы минимальное
сечение по лучшему способу монтажа. Нет коэффициентов спроса ПУЭ (один тип),
паспортных ВТХ (→ `selective: null`), MCP-ресурсов.

## Спецификация и маркировка (волна 14, `src/cabinet_spec.py`)

Перечень, обозначения по ГОСТ 2.710-81 и шильды из раскладки; нумерация по
порядку на плате. **Для УЗО кода в ГОСТ 2.710-81 нет** — позиция уходит в
`unresolved`. Таблица `designations` — цитата стандарта, `designation_map`
(изделие → код) **составлена**. `unwrap` разворачивает ответ раскладчика.

## Корпуса щита (волна 15, `src/cabinet_enclosure.py`)

1150 корпусов IEK в `data/cabinet_enclosures.example.json`, добыты из блока
**ETIM** открытого каталога (признак = идентификатор: `EF002950` модули,
`EF000266` ряды, `EF005474` IP). **Аппарат ставится на плату, корпус есть
плата** — поэтому для корпуса `item_to_layout` отказывает. Ширина ряда =
`modules / rows × 18` — **расчётная**, помечена `derived`; габарит монтажной
панели производитель не публикует → `None`. Добыча: обходить дерево
подкатегорий (листинг режет на 80) и добавлять префикс `/products/catalog`.

## Схема как модель данных (волна 16, `src/cabinet_schematic.py`)

Модель: устройства → зажимы → цепи → соединения; шесть видов через `kind`.
**Схему нельзя вывести из раскладки**: раскладка знает координаты, не связи, —
соединения приносит caller или шаблон. Графы таблицы соединений («Конт.»,
«Адрес», «Цепь», «Адрес внешний») — цитата ГОСТ 2.702-2011, а **нумерации цепей
в нём нет** (слова «маркировка» в тексте нет) → обозначение цепи от caller,
шаблонное — `derived`. Зажимы = `2 × poles`, `derived`; нет полюсов → отказ
`no_terminals`. Цепь с `external_address` не считается разомкнутой. 59
инструментов, 645 тестов.

## Сборка и остатки

Патчи `waveN.patch` — на чистую базу последовательно; гейты числа
инструментов — по `test_wave1`–`16` (правкой одной цифры во всех).
`VERSION.json` и каталог должны совпадать **по порядку** имён, не только по
множеству. **Лицензии в репозитории нет** — блокер внешнего использования.
Остатки — в `mcp_servers_comparison.md`: чтение схемы из документа КОМПАС,
нагрев НКУ, STEP → `.m3d`, запись в документ, поиск, AAS/AASX.
