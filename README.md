# KOMPAS-3D MCP

Репозиторий проекта моста к КОМПАС-3D через MCP с щитовым доменом
(проектирование низковольтных НКУ).

## Состав

| Каталог / файл | Что здесь |
|---|---|
| `kompas-3d-ai-bridge-main/` | сам мост: `src/` — доменные модули, `mcp/` — MCP-сервер и каталог инструментов, `tests/` — 645 тестов, `data/` — каталоги изделий и нормативные таблицы, `docs/` — описания волн |
| `research/` | материалы сравнительного исследования MCP-серверов (черновики, выгрузки, заметки) |
| `wave*.patch` | патчи волн в том порядке, в котором они накладывались |
| `mcp_servers_comparison.md` | сравнительная таблица серверов и список остатков |

## Что умеет щитовой домен

Состав и секционирование по ГОСТ IEC 61439-2, раскладка монтажной панели в
миллиметрах, материализация в документ КОМПАС, сверка перечня, электрорасчёт,
подбор по каталогу (изделия и корпуса IEK), нормативные таблицы ГОСТ/ПУЭ как
данные, перечень и маркировка по ГОСТ 2.710-81, схема как модель данных с
таблицей соединений по ГОСТ 2.702-2011. Всего 59 инструментов.

## Главная дисциплина

Неподтверждённое не подменяется правдоподобной оценкой. Нет данных — отказ с
причиной (`refusals`, `unverified`, `not_checked`), а не догадка. Нормативные
величины приходят из `data/normative` с указанием источника, который
возвращается в `provenance`; расчётные значения помечены `derived`.

## Требования

Работа с документами требует КОМПАС-3D v25 x64 под Windows и pywin32. Все
доменные модули — чистые функции и тестируются без КОМПАС.
