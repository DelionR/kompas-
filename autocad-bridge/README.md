# Адаптер AutoCAD

Отдельная подпапка проекта: файлы, адаптированные под AutoCAD, живут здесь,
а не рядом с мостом КОМПАС. Домен щита общий, CAD-слой — свой.

## Целевая сборка

| Что | Значение |
|---|---|
| Версия | **AutoCAD 2019.1.2** (`P.162.0.0`) |
| Релиз | **R23** |
| ProgID | **`AutoCAD.Application.23`** |
| Вертикаль | AutoCAD Electrical 2019.0.1 Update — тот же ProgID |

Номер релиза взят из опубликованной таблицы ProgID Autodesk, а не угадан:
2019 → R23, 2020 → R23.1, 2021 → R24, 2024 → R24.3. Релиз вне таблицы
адаптер не обслуживает.

## Состав

| Файл | Что делает |
|---|---|
| `src/autocad_version.py` | релиз → ProgID, парсинг строки версии, матрица подтверждённых сборок |
| `src/autocad_units.py` | `INSUNITS` → масштаб и перевод миллиметров в единицы чертежа |
| `src/autocad_layout.py` | раскладка щита → точки вставки блоков (чистые функции) |
| `src/autocad_session.py` | подключение к уже открытому AutoCAD, чтение документа |
| `src/autocad_tools.py` | действия адаптера |
| `mcp/tools_catalog.py` | каталог инструментов и маршруты |
| `tests/test_autocad_adapter.py` | 43 теста, COM подменяется моком |

## Главное отличие от КОМПАС

Раскладка щита считается в миллиметрах, начало координат **сверху слева**,
`+y` вниз. В AutoCAD начало **снизу слева**, `+y` вверх. Поэтому координата Y
не просто масштабируется, а **разворачивается относительно высоты платы**:

```
y_acad = origin_y + (H - y_layout - h) * k
```

Отсюда следствие: **без высоты платы перевод невозможен** — отказ
`no_plate_height`. Оценить высоту панели «на 20 мм меньше корпуса» значило бы
выдать оценку за расчёт.

Второе отличие — **единицы чертежа**. Домен считает в миллиметрах, а документ
AutoCAD может быть в дюймах, в метрах или вовсе без единиц (`INSUNITS = 0`).
Масштаб выясняется до всякой записи; документ без единиц — отказ.

## Дисциплина

Та же, что в мосте КОМПАС:

- **Не запускаем CAD.** Только `GetActiveObject` к уже открытому экземпляру:
  иначе агент подменит чертёж, с которым работает человек.
- **Отказ вместо правдоподобной подстановки.** Нет единиц — отказ. Нет высоты
  платы — отказ. Релиз вне таблицы — отказ. Неизвестный код единиц не
  считается миллиметрами.
- **Матрица версий пуста по умолчанию.** Уровень `unverified` означает «не
  проверено», а не «разрешено». Заполняет её оператор.
- **Ничего не пишем.** На этом этапе адаптер отдаёт данные и координаты.

## Чего здесь нет

- **Записи в чертёж.** Нет ни вставки блоков, ни слоёв, ни экспорта: всё это
  появится после приёмки на живой машине.
- **Проверки, что запущен именно Electrical.** По COM это надёжно не
  определяется — отдельного ProgID у вертикали нет. Профиль приносит оператор
  и помечается `unverified`.
- **Electrical-специфики**: провода, клеммы, позиционные обозначения по ГОСТ
  2.702 в терминах Electrical.

## Статус

AutoCAD на машине разработки отсутствует (проверено по реестру: ни
`AutoCAD.Application.*`, ни раздела `Autodesk`). COM-слой не исполнялся,
приёмка — за оператором. Всё, что можно проверить без AutoCAD, проверено
43 тестами.
