Щитовое оборудование и АСУ ТП на GitHub: что есть под КОМПАС-3D и SolidWorks

Обзор открытых репозиториев (сентябрь 2026). Искал по GitHub Search API — 62 запроса, ~300 уникальных репозиториев, отобрано 60 по теме: проектирование щитов/НКУ, шкафы АСУ ТП, автоматизация КОМПАС-3D и SolidWorks, MCP-мосты к CAD.

Главный вывод

  • Готовых opensource-библиотек «щиты для КОМПАС-3D» не существует — и это проверено на двух языках. По-русски ноль дают: компас щит, компас шкаф, компас НКУ, компас электрощит, компас электромонтаж, электрощит, шкаф управления, низковольтное комплектное устройство. По-английски ноль дают: kompas cabinet, kompas 3d cabinet, kompas3d cabinet, kompas electrical cabinet, kompas switchgear, kompas distribution board, kompas3d electrical, kompas3d library. Ниша пустая по-настоящему.
  • Лучший рабочий эталон щитовой логики — Taam4142/cabinet-layout-generator-v2: раскладка монтажной панели щита в браузере с экспортом настоящего DXF (MIT, живой проект).
  • Лучший источник русской доменной логики НКУ/АСУ ТП — postall74/TaCP: дерево шкафов (ГРЩ, ВРУ, АВР, шкаф ПЛК), секционирование по ГОСТ IEC 61439-2, проверки совместимости.
  • Новое после второй волны — managallment-svg/lv-panel-designer-pro: веб-платформа расчёта и компоновки низковольтных щитов (MDB, SMDB, MCC, ATS, APFC, Feeder Pillar) с расчётом шин, проверкой Icw, GA-чертежом, BOM и PDF. Плюс экспертная система на PyKnow и генератор этикеток для щитов.
  • Под SolidWorks всё уже есть: xCAD, CodeStack, SolidDNA, pySolidWorks и минимум 4 разных MCP-сервера. Под КОМПАС API-обёртки есть, а MCP — шесть разрозненных проектов, самый сильный из которых dwnmf/KOMPAS-3D-MCP-bin (28 ★).

Вывод третьей волны: гипотеза «русские щитовики просто не выкладывают код на GitHub» не подтвердилась полностью — дело не в языке. По-английски щитовых проектов тоже нет ни под КОМПАС, ни в принципе в заметном количестве. Единственные живые щитовые инструменты — те, что делают коммерсанты для себя (cabinet-layout-generator, TaCP, lv-panel-designer-pro).

Что это значит для KOMPAS-3D MCP

  • Ниша подтверждена пустотой. Семь целых запросов вида «КОМПАС + щит/шкаф/НКУ/электрощит» — ноль репозиториев. При этом щитовики в РФ массово сидят на КОМПАС. Открытой параметрической библиотеки корпусов, DIN-реечного оборудования и УГО под КОМПАС просто не существует.
  • Архитектуру берите у cabinet-layout-generator-v2: одна валидированная JSON-модель раскладки → один рендерер → DXF/PDF/чертёж. Правило «код ничего не угадывает, неизвестное флагуется» спасает от дорогих ошибок в цеху.
  • Домен берите у TaCP: дерево шкафов, составные корпуса, секционирование по ГОСТ IEC 61439-2, проверки совместимости (автомат↔шина, ПЛК без БП 24 В и т.п.), конфигуратор ПЛК. Это готовое ТЗ на модуль «собрать щит».
  • Мост к CAD делайте по образцу covagashi/eplan-rag-mcp: MCP-сервер + RAG по SDK + агентский skill. У EPLAN это уже работает (96 ★); у КОМПАС — три зачаточных проекта (geomwright, hymaxo/kompas3d-mcp, EMX302/AI-to-CAD-Bridge-SW-), ни один не закрепился.
  • Базу для инструментов берите у nikitamamay/KompasAPI-01 (типизированная обёртка + стабы) — иначе каждый инструмент MCP придётся писать вслепую по COM.
  • Параметрическую сборку пока негде подсмотреть, кроме baalp/TheScrewdriverGenerator — это единственный найденный пример программной сборки изделия в КОМПАС по параметрам.
