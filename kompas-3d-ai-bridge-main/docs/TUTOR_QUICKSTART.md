# Быстрый старт: режим наставника

Как превратить мост в инструмент для обучения новичка работе в КОМПАС-3D.

## Что это даёт

Новичок учит КОМПАС, а не MCP. Он не видит JSON и не знает, что такое COM.
Он отвечает на вопросы, называет размеры — и сразу видит результат
в живом окне КОМПАС плюс числа, прочитанные из модели.

Агент при этом:

- объясняет операцию до выполнения;
- даёт новичку самому задать параметры;
- выполняет один шаг за раз;
- показывает результат двумя каналами — числа из API и скриншот;
- проверяет сохранение переоткрытием;
- не выдаёт неподтверждённое за подтверждённое.

## Требования

- Windows, обычная сессия без прав администратора
- Запущенный КОМПАС-3D v25 x64 в той же сессии пользователя
- Python 3.11 и `pywin32`
- Распакованный мост (рекомендуемая цель `C:\KOMPAS_AI_BRIDGE`)

## Запуск

Все команды — из обычного PowerShell, без повышения прав.

1. Установить зависимости:

   ```
   python -m pip install -r .\requirements.txt
   ```

2. Проверить зависимости и контракты:

   ```
   python .\common\dependency_check.py
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\RUN_STATIC_TESTS.ps1 -Root (Resolve-Path .)
   ```

3. Запустить watchdog/worker — оставить это окно открытым:

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap\START_BOOTSTRAP_SAFE.ps1 -Root (Resolve-Path .)
   ```

4. Проверить статус во втором окне:

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap\BootstrapClient.ps1 -Action status -Root (Resolve-Path .)
   ```

5. Поднять MCP-сервер в клиенте агента:

   ```
   python .\mcp\kompas_mcp_server.py --root (Resolve-Path .)
   ```

## Первый урок

Скажи агенту:

> Загрузи режим наставника `kompas-tutor` и начни урок 1 из каталога `lessons/`.
> Я новичок в КОМПАС-3D.

Агент загрузит `skills/kompas-tutor/SKILL.md`, откроет
`lessons/lesson-01-orientation.json` и пойдёт по шагам.

Если урок не первый, назови номер:

> Начни урок 4 — отверстия.

## Проверка, что всё работает

Перед первым уроком убедись, что агент видит КОМПАС:

> Проверь статус КОМПАС и скажи, какой документ активен.

Ожидаемый ответ: версия КОМПАС, список открытых документов, путь активного.
Если агент не видит КОМПАС — мост не запущен или запущен в другой сессии пользователя.

## Чем это отличается от `kompas-engineering`

| | `kompas-engineering` | `kompas-tutor` |
|---|---|---|
| Цель | готовая модель | понимание в голове новичка |
| Кто решает | агент | новичок при подсказках агента |
| Темп | максимально быстрый | один шаг, пауза на вопрос |
| Ошибка | починить и идти дальше | показать и объяснить |

Для реальной инженерной работы используй `kompas-engineering`.
Для обучения — `kompas-tutor`.

## Ограничения, о которых знает наставник

Наставник предупреждает о них заранее, а не после того, как новичок упрётся:

- примитив добавляется только в пустую деталь, один раз;
- отверстия — только в плоскости XOY;
- сопряжение создаётся по одному за вызов, с проверкой счётчика;
- линейный массив — от 2 до 20 экземпляров;
- перенос компонента — не более 5 мм за вызов;
- успешный вызов экспорта не означает, что файл непустой.

## Безопасность

Работа идёт только с файлами, в имени которых есть `_AGENT_COPY`.
Исходники новичка мост не открывает для записи. Перед каждой мутирующей
операцией создаётся байтовый снимок: список — `kompas_checkpoints`
с `operation: "list"`.
