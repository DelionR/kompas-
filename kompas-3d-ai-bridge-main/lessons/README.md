# Уроки KOMPAS-3D через MCP

Пошаговые сценарии для изучения КОМПАС-3D под руководством ИИ-наставника.
Файлы уроков читает агент; новичок работает с КОМПАС через диалог, а не через этот каталог.

## Как это работает

Агент загружает `skills/kompas-tutor/SKILL.md`, берёт сценарий урока из этого каталога
и ведёт новичка по циклу:

```
скажи, что будет → дай новичку решение → выполни один MCP-вызов
→ покажи числа из API → покажи скриншот → свяжи число с формой → спроси перед следующим шагом
```

Новичок не читает JSON. Он отвечает на вопросы и называет параметры.

## Уроки

| # | Файл | Тема | Что осваивается |
|---|---|---|---|
| 1 | `lesson-01-orientation.json` | Ориентация | `kompas_status`, активный документ, дерево, габарит, скриншот |
| 2 | `lesson-02-first-part.json` | Первая деталь | `kompas_part_create`, `kompas_part_add_primitive` (block) |
| 3 | `lesson-03-primitives.json` | Три примитива | block / plate / rect_tube, толщина стенки, полое тело |
| 4 | `lesson-04-holes.json` | Отверстия | `kompas_part_add_hole`, through / blind, плоскость XOY |
| 5 | `lesson-05-material.json` | Материал и масса | `kompas_material_read`, `kompas_material_set`, evidence-source |
| 6 | `lesson-06-assembly.json` | Сборка | `kompas_assembly_create`, вставка компонентов, BOM |
| 7 | `lesson-07-mates.json` | Сопряжения | `kompas_mate_read`, `kompas_mate_create`, проверка счётчика |
| 8 | `lesson-08-export.json` | Контроль и экспорт | `kompas_export`, `kompas_artifact_check`, ссылки, чекпоинты |

Уроки идут последовательно: каждый опирается на предыдущий.
Уроки 1 — только чтение. Начиная с урока 2 мост создаёт файлы.

## Формат сценария

```json
{
  "id": "lesson-02",
  "title": "Название",
  "goal": "чего достигаем",
  "concepts": ["список"],
  "prerequisites": ["lesson-01"],
  "safety": "что гарантируется",
  "steps": [
    {
      "id": "s1",
      "say": "что сказать новичку перед действием",
      "tool": "kompas_part_create",
      "args": {"filename": "..."},
      "ask": "вопрос, заставляющий новичка подумать",
      "explain": "объяснение после действия",
      "warn_before": "предупреждение об ограничении",
      "verify": [{"look": "поле", "question": "что проверить"}]
    }
  ],
  "quiz": [{"q": "вопрос", "a": "ответ"}],
  "success_criteria": ["что новичок должен уметь"],
  "next": "lesson-03-primitives"
}
```

Поле `args` — предложение по умолчанию, а не обязательные значения.
Агент спрашивает новичка, какие параметры он хочет задать, и берёт `args` только если
новичок отвечает «не знаю» или «любые».

## Требования

- Windows, запущенный КОМПАС-3D v25 x64
- Настроенный и запущенный мост (см. `CAP2_SETUP_AND_RUN.md`)
- MCP-сервер, подключённый к клиенту агента

## Безопасность

Все уроки работают только с файлами, в имени которых есть `_AGENT_COPY`.
Исходные документы новичка мост не трогает. Перед каждой мутирующей операцией
создаётся байтовый снимок — откат возможен через `kompas_checkpoints`.
